CodeAlpha Python Internship Tasks
Python programs I built during my Python Programming Internship at CodeAlpha (20 May 2026 – 20 June 2026).
Projects
1. Stock Portfolio Tracker
File: codealpha_Stock Portfolio Tracker.py
Asks how many stocks you own, then takes each stock name and quantity.
Looks up the price from a built-in dictionary (AAPL, TSLA, GOOG, MSFT).
Shows the investment for each stock and the total investment value.
Reports "Stock not found" for stocks that are not in the dictionary.
2. Basic Chatbot
File: codealpha_basic chatbot.py
A simple rule-based chatbot that runs in a loop.
Replies to "hello" and "how are you".
Ends the chat when you type "bye".
Says "I don't understand" for any other input.
Input is not case sensitive.
3. Hangman Game
File: codealpha_hangman.py
Picks a random word from a list and shows it as blanks.
You guess one letter at a time and get 6 wrong attempts.
Repeated guesses are not counted.
Ends with a win message or a game over message that shows the word.
How to run
Install Python 3.
Clone this repository:
git clone https://github.com/praveenprakash99/codealpha_tasks-.git
cd codealpha_tasks-
Run any program (use quotes because some file names have spaces):
python "codealpha_Stock Portfolio Tracker.py"
python "codealpha_basic chatbot.py"
python "codealpha_hangman.py"
